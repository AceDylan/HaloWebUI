# Halo Motion

The three services share identical CSS springs and timing tokens, generated by `spring.py` (a damped spring normalized to settle at the end of its duration). No new runtime dependencies or external fonts are required.

| Token | Value | Use |
| --- | --- | --- |
| `--dur-micro` | 160ms | small controls |
| `--dur-std` | 240ms | menus, panels, tab navigation |
| `--dur-hero` | 560ms | first message, sign-in, camera focus |
| `--dur-exit` | 140ms | dismissal |
| `--stagger` | 36ms | at most three layers, total under 300ms |
| `--recede-scale` | .975 | surrounding layer recedes |
| `--dof-blur` | 4px | reserved for desktop only; disabled on mobile |

CSS uses a cubic fallback where `linear()` is unavailable. Reduced motion uses only a short opacity change. Hidden tabs pause CSS decoration and cancel camera work. Frequent paths never wait for an animation to finish. Each operation has at most one main camera move; new pointer/wheel input interrupts it.

Live editor text, streaming responses and long reading/list surfaces never receive ongoing motion. Menus use their trigger edge as transform origin. Mobile excludes glow, dust, blur and parallax.

WebObsidian retains explicit Obsidian themes. Halo has ink/white surfaces, ion blue accents and self-hosted Mona Sans headings. Its knowledge scene always stays night: actual backlinks, folder counts, selectable note details. Aggregation is a presentation layer, with no writes to vault data. Folder/core hierarchy edges are distinct from aggregated backlinks internally. Graph labels and detail cards use opaque surfaces.

Hub framing sends `{source:'hub', type:'enter'}` only to configured peer origins. Peers accept it only from the parent window on the configured Hub origin, using the same trust boundary as existing theme messages.

The optional Hub bookmark star map is excluded: its data is a directory tree, so it would imply relationships that do not exist. The star-core wallpaper is a static asset generated by the existing wallpaper tool. WebObsidian glow uses bounded layered geometry; no Bloom postprocessing dependency is added.
